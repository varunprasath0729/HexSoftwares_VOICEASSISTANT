**Voice Assistant in Python**

This project is a simple Python-based voice assistant that can listen to user commands, understand speech, perform basic tasks, and give voice responses.
It uses speech recognition and text-to-speech libraries to automate common actions.

**Features**

Listens to voice commands
Converts speech to text
Responds using text-to-speech
Opens websites and applications
Searches Wikipedia and Google
Plays YouTube videos
Tells date and time
Sends emails

**Technologies Used**

Python 3
speech_recognition
pyttsx3
wikipedia
pywhatkit
webbrowser
datetime
